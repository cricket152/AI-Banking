# AI Banking PPT制作素材

从ppt-production-guide.docx开始，按10页、8分40秒的讲解节奏制作答辩PPT。slides.json包含逐页配文、讲稿和配图安排；assets包含14张运行原图、4张细节图和3组PNG/SVG架构机制图。asset-manifest.json记录尺寸、来源与SHA256。

本包不制作或附带新的PPTX。截图来自独立虚构环境，涉及Agent的业务演示为脚本化演示；保留模拟标识、状态与图注。运行图中的A至D是确定性安全检查。日期计划须手动触发、卡片与理财写操作由界面办理，按指南表达。

请将标题、正文和流程节点做成可编辑元素。原图按比例展示，优先用SVG重绘架构。已裁切的细节图只改变取景范围，不更改界面文字、数额和结果。不要裁掉批准或成功状态后改变含义。
