# 能力、工具与页面素材

工具按业务能力拆分是为参数校验、权限边界与审计；不是每个用户说法创建一个工具。用户意图可以组合多次调用，模型不决定身份或批准。本项目保持单主Agent，查询与意图准备工具共12个。

| 工具 | 用途 | 允许副作用 |
| --- | --- | --- |
| list_accounts | 本人账户余额 | 无 |
| get_transactions | 最近流水样本 | 无 |
| list_payees | 本人已登记收款账户 | 无 |
| list_subscriptions | 已登记订阅 | 无 |
| get_billing_summary | 指定区间账单统计 | 无 |
| prepare_transfer | 准备转账意图 | 创建待确认操作；指定有效预授权时可在应用复核后执行 |
| prepare_subscription_cancellation | 准备取消意图 | 同上，取消不退款 |
| get_operation | 查询原操作状态 | 无新付款 |
| list_cards | 脱敏模拟卡片 | 只读 |
| list_wealth_products | 模拟理财目录 | 只读 |
| get_billing_entries | 分页核对账单原流水 | 无 |
| find_payees | 名称/备注/尾号包含查询 | 无；多个匹配需澄清 |

登记订阅、载入联系人、密码复核、创建/撤销授权、批准/拒绝来自显式页面操作，不开放给模型。Agent对卡片、日期场景计划与理财数据只读/解释；没有对应写工具，申请或操作由界面发起。工具名称中的prepare不代表永远不会执行：转账/订阅的预授权模式仍可能经应用与银行逐次复核后完成。

比赛场景映射：账单分析、订阅管理、智能转账已有闭环；另有两种边界不同的能力：固定的“取消所选订阅后转固定金额”工作流，以及只保存日期/预算的日期场景计划。日期计划创建时仅校验可用余额、不冻结或预留资金；下单必须由用户手动点击界面按钮，后续仍待确认。Agent对场景计划、理财和卡片只读/解释。手机号转账、定时转账、AA收款、订阅闲置识别、自动续费任务、生日资金锁定与外部预订均不在当前完成清单中。
