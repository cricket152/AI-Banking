# 架构图来源
使用 https://github.com/tt-a1i/archify 的本地工具制作，编辑源为 architecture.archify.json。工具本身保存在忽略目录 .local，不成为项目运行依赖。
本图核心模块使用已提交2b63eba作为代码证据；新增未提交功能未伪装成该提交内容，详见技术初稿与当前工作树哈希清单。可选LangSmith不在主路径图内，不参与资金事实。
HTML可独立打开；PNG/SVG供材料排版。工具自动校验与人工视觉检查结果另记。

当前版本的有效验收回执在 `review-3/`，视觉捕获在 `visual-review/`；根目录早期 finalize / browser-check 回执与 `review-2/` 仅保留工具过程记录，不能作为当前图像字节的校验证明。当前图像 SHA256 以 `review-3/system-architecture.finalize-summary.json` 为准。
