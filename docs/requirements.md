## 验收标准

### Phase 0

- 文档、通用配置、Issue / PR 模板及 `src/`、`tests/` 占位目录齐备。
- Git 使用 `main`，`origin` 指向指定仓库；远程检查结果可追溯，推送前获得明确批准。
- 协作流程覆盖独立分支、另一位成员审查、主分支同步和实际验证记录。
- 不包含业务实现、虚构规则、真实凭据或不可执行的 CI。
