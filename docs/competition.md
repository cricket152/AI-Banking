### 官网列出的场景

| 场景 | 公开描述 |
| --- | --- |
| 智能转账 | 按人名、手机号或备注转账；定时转账；拆分 AA 收款 |
| 账单分析 | 消费分类统计；异常交易识别；月度、年度账单报告 |
| 理财操作 | 产品推荐与对比；风险评估；一键申购、赎回 |
| 卡片管理 | 卡片申请；额度调整；交易限制、解锁；卡片挂失 |
| 订阅 / 代扣管理 | 识别订阅扣费；续费提醒；一键取消订阅 |
| 跨场景联动 | 官网示例：识别生日需求、锁定资金并自动完成鲜花或蛋糕等服务预订 |

用户提供的截图对此场景描述为：识别爱人生日、当月锁定 1000 元活期资金，并在生日两天前订购鲜花 / 蛋糕。该文案与官网公开赛题页的示例不同；执行细节以主办方最终规则核实为准。

官网强调 AI 代办银行业务中的安全与体验。权限分级、授权参数和安全评测细项仍需完整规则核实；本仓库的安全契约属于项目设计，不应误称为官方评分条款。
