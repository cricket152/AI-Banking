- 真实密钥与本地凭据不入库；`.env.example` 仅记录已确认的变量及安全示例。
- 当前没有真实自动化检查任务，不创建 CI；引入可执行检查时同步补充本地命令与工作流。

后续每项重要决策记录背景、选项、结论、影响和确认日期；已确定的整体架构变更应先取得明确确认。
